# Student Feature Package

Student screens. Faculty extends these classes, so changes here apply to both account types.

- `StudentHomeActivity.java` - greeting, points, quick access, recommended listings, community highlights
- `StudentMarketActivity.java` - Firestore listings + samples, search, filter, sort
- `StudentCommunityBoardActivity.java` - live posts, filters, "Interested" stars
- `StudentMessagesActivity.java` - live chats and requests
- `StudentLeaderboardActivity.java` - rewards: points, vouchers, tiers
- `StudentProfileActivity.java` - profile stats and menu

Orders, reviews, listings and chat screens are shared (see `shared/`).
